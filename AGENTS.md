# Agent Guidelines

## This repository is public

Everything committed here, and every issue, PR, comment and commit message, is public. Nestled is used by
operators we don't know, on installations we must never identify.

- **Never name a downstream project, client, organization or site,** and never link a private repository:
  not in code, comments, tests, docs, fixtures, issues or commit messages. Use placeholders such as
  `project-a` or `example-app`.
- **Never describe an unfixed vulnerability publicly.** Security problems go through private vulnerability
  reporting; the fix ships first, and a generic advisory follows.
- **Issues are filed here,** written against the package version, with a minimal reproduction where possible.
